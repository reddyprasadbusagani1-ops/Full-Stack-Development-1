# Experiment 10: Node.js Basics

## Aim
To introduce Node.js as a JavaScript runtime and run basic server-side JavaScript programs.

## Requirements
Install the current Node.js LTS version from https://nodejs.org/. During installation, keep the option to add Node to PATH enabled.

## Programs
- `hello.js` — basic console output
- `input-add.js` — read two numbers from the terminal and add them
- `server.js` — a small HTTP server

## Run on Windows
Open Command Prompt in this folder and run:
- `node hello.js`
- `node input-add.js` then enter the requested values
- `node server.js`, then open http://localhost:3000 in your browser. Stop the server with Ctrl+C.

No third-party npm packages are required.
