# Experiment 1: Lists, Links and Images

## Aim
To demonstrate HTML ordered, unordered, nested and definition lists, hyperlinks, profile images, and thumbnail image galleries.

## Programs
1. `lists.html` — list types and nesting
2. `hyperlinks.html` — anchor tag with `href` and `target`
3. `profile-images.html` — two profile images linked to profile pages
4. `thumbnail-gallery.html` — thumbnails linked to full-size images

## Run
Open any HTML file in a web browser. Replace sample names and profile URLs with your own details if required.
