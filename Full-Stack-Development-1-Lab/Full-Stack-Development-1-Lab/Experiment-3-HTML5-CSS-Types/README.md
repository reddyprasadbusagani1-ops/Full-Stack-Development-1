# Experiment 3: HTML5 and CSS Types

## Aim
To demonstrate semantic HTML5 elements, audio/video embedding, and inline, internal, and external CSS.

## Programs
- `semantic-elements.html`
- `media-demo.html`
- `css-types.html` with `styles.css`

## Run
Open each HTML file in a browser. The media example uses public sample media URLs and requires internet access.
