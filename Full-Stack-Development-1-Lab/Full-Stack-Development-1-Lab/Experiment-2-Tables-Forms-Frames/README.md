# Experiment 2: HTML Tables, Forms and Frames

## Aim
To create HTML tables with merged cells, a timetable, a registration form, and a page layout using frames/iframes.

## Programs
- `table-demo.html`
- `timetable.html`
- `registration-form.html`
- `frames.html` — modern iframe alternative
- `legacy-frameset.html` — legacy frameset syntax for syllabus demonstration

## Run
Open each HTML file in a browser. The registration form demonstrates layout and client-side required fields; it does not submit data to a server.
