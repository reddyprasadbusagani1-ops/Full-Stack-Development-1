## Overview
This repository contains beginner-friendly runnable programs based on the supplied syllabus. Experiments 1–9 follow the syllabus topics, with Node.js examples included as an additional section.

## Folder structure
- `Experiment-1-Lists-Links-Images/`
- `Experiment-2-Tables-Forms-Frames/`

- `Experiment-4-CSS-Selectors/`
- `Experiment-5-CSS-Color-Background-Text-Box-Model/`
- `Experiment-6-JavaScript-IO-Type-Conversion/`
- `Experiment-7-JavaScript-Objects/`
- `Experiment-8-Conditionals-Loops/`
- `Experiment-9-Functions-Events-Validation/`
- `Experiment-10-NodeJS/`

Each experiment folder has its own README and files.

## Requirements
- Windows 10/11, macOS, or Linux
- A modern web browser (Chrome, Edge, or Firefox)
- A text editor such as Notepad or VS Code
- Node.js LTS only for Experiment 10

## Run HTML/CSS/JavaScript programs
1. Extract the ZIP.
2. Open the relevant experiment folder.
3. Double-click an `.html` file to open it in your browser.
4. For programs using `prompt()` or `alert()`, allow browser dialogs.
5. For CSS examples, open the HTML file and inspect the displayed styles.

## Run Node.js programs on Windows
1. Install Node.js from https://nodejs.org/ and choose the LTS version.
2. Open Command Prompt in the `Experiment-10-NodeJS` folder.
3. Run a file with `node filename.js`, for example:
   `node hello.js`

## Important notes
- Some programs use browser prompts for input; enter the values requested.
- `frames.html` demonstrates the legacy `<frameset>` concept required by the syllabus. Modern HTML5 does not support `<frameset>`; an iframe-based alternative is also included.
- The image gallery uses placeholder remote images from `picsum.photos`; internet access is needed to load them. Replace them with your own images if preferred.
- Registration validation is for lab practice only and is not a production security system.
- The JDBC lab is separate; this package covers HTML, CSS, JavaScript, and Node.js.
