# Experiment 9: JavaScript Functions, Events and Form Validation

## Aim
To implement factorial, Fibonacci series, prime numbers, palindrome checking, and registration field validation.

## Programs
- `number-functions.html` — four buttons call separate functions
- `registration-validation.html` — validates name, mobile number, and email

## Validation rules
- Name starts with a letter, then contains only letters/digits, minimum 6 characters.
- Mobile number contains exactly 10 digits.
- Email uses a basic `local@domain.extension` pattern.

## Run
Open the HTML file in a browser. Enter a non-negative integer for number functions. These are educational client-side checks, not production security.
