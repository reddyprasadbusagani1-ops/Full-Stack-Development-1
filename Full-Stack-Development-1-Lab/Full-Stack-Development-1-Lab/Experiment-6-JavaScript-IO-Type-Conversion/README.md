# Experiment 6: JavaScript I/O and Type Conversion

## Aim
To demonstrate internal/external JavaScript, output methods, input methods, type conversion, and voter eligibility.

## Programs
- `internal-external.html` and `external.js`
- `output-methods.html`
- `input-methods.html`
- `voter-eligibility.html`

## Run
Open the HTML files in a browser and follow the prompts. Use browser developer tools (F12) to see console output.
