# Experiment 5: CSS Color, Background, Font, Text and Box Model

## Aim
To demonstrate CSS color formats, fixed background image positioning, font/text properties, and the CSS box model.

## Programs
- `color-formats.html`
- `fixed-background.html`
- `font-text.html`
- `box-model.html`

## Run
Open each HTML file in a browser. Scroll `fixed-background.html` to observe the fixed background.
